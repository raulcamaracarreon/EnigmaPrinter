# EnigmaPrinter

### *In the Beginning was the Word.*

The primary EnigmaPrinter documentation is now maintained in English in [`README.md`](README.md).

EnigmaPrinter is an **audio-first AI video production** project derived from [MoneyPrinterTurbo](https://github.com/harry0703/MoneyPrinterTurbo) by Harry and contributors.

It adds an independent development path focused on narration-aware timing, semantic shot planning, visual continuity, AI image/video generation, hybrid media planning, and timeline-aware composition.

➡️ **[Read the main EnigmaPrinter README](README.md)**

The original MoneyPrinterTurbo English documentation remains available in the [upstream repository](https://github.com/harry0703/MoneyPrinterTurbo/blob/main/README-en.md).
