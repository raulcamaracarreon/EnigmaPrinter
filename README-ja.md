# EnigmaPrinter

### *In the Beginning was the Word.*

EnigmaPrinter の主要ドキュメントは現在、[`README.md`](README.md) に英語で掲載しています。

EnigmaPrinter は、Harry 氏とコントリビューターによる [MoneyPrinterTurbo](https://github.com/harry0703/MoneyPrinterTurbo) を基にした **audio-first AI video production** プロジェクトです。

独自の開発方針として、音声ナレーションを時間構造の基準にし、セマンティックなショット計画、視覚的一貫性、AI 画像・動画生成、ハイブリッドメディア計画、タイムライン対応コンポジションを追加しています。

➡️ **[EnigmaPrinter のメイン README を読む](README.md)**

MoneyPrinterTurbo の日本語ドキュメントは、[アップストリームのリポジトリ](https://github.com/harry0703/MoneyPrinterTurbo/blob/main/README-ja.md) で引き続き参照できます。
